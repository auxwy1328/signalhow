Signal 隐私设置完全指南：9 个必须开启的安全选项

📅 2026年5月4日 🏷 Signal, 隐私保护, 安全设置, 教程, 入门指南

很多人下载 Signal 后直接开始聊天，从来没有碰过设置页面。这就像买了一辆安全性能顶级的汽车，却从来不锁车门——工具再好，设置不对也白搭。

这篇文章会带你把 Signal 的 9 个关键隐私设置全部开启。每个设置我都会解释"为什么重要"和"怎么开"，不会只给你步骤列表。

1. 消失消息：让聊天记录自动销毁

这是 Signal 最实用的隐私功能，也是很多人不知道的。

什么是消失消息？ 你可以设置一个时间（从 1 秒到 4 周），消息在这个时间后会在双方设备上自动删除。不是"标记为已删除"，是真的从设备上抹掉。

为什么重要： 即使你的手机被别人拿到、丢失、或者被没收，这些消失消息也不会泄露。Signal 官方在 2023 年发布过一份安全白皮书，明确指出消失消息可以保护用户在"威胁模型升级"场景下的安全。

怎么开：

  • 打开和对方的聊天 → 点击右上角"⋯" → 开启"消失消息" → 选择时间
  • 全局设置：Signal 设置 → 隐私 → 默认消失消息计时器 → 选择全局默认时间

建议： 日常聊天设置 1 周，敏感对话设置 1 天或 1 小时。不建议设成"关"，因为就算你不设置，聊天记录也存在你手机上。

2. 屏幕安全锁：防止别人偷看

你有没有过这种经历：手机放在桌上，有人趁你不注意翻看你的微信？Signal 的屏幕安全锁可以防止这种情况。

开启后： 每次打开 Signal 都需要输入 PIN 码或用指纹/面容解锁。即使手机已经解锁，打开 Signal 还是需要二次验证。

怎么开： Signal 设置 → 隐私 → 屏幕锁 → 开启 → 设置 PIN 码

一个细节： 2024 年 Signal 更新后，屏幕锁支持"自动锁定"时间设置。你可以选择"立即锁定"或"离开 Signal 后 X 分钟锁定"。如果你经常离开工位，建议设成 1 分钟。

3. 注册锁：防 SIM 卡劫持

这是被严重低估的安全功能。2024 年出现过大量 SIM 卡劫持攻击案例：攻击者冒充你，去运营商那里补办一张你的手机号 SIM 卡，然后用这个号码登录你的各种账户（包括 Signal）。

注册锁的作用是：即使攻击者拿到了你的 SIM 卡，如果没有你的 Signal PIN 码，也无法在 new device 上注册你的 Signal 账号。

怎么开： Signal 设置 → 账户 → 注册锁 → 开启 → 设置 PIN 码

重要： 记住这个 PIN！如果忘了，你需要重新注册 Signal 账号（旧账号的所有聊天记录会丢失）。建议把 PIN 记在密码管理器里，不要写在手机备忘录上。

4. 用户名代替手机号：隐藏真实身份

2024 年 Signal 正式推出了用户名功能。这是一个里程碑式的隐私更新。

之前的问题： 你的手机号就是你的 Signal 身份。任何人只要知道你的手机号就能在 Signal 上找到你，你的手机号会显示在个人资料里。

现在的做法： 你可以设置一个用户名（比如 @tomato_2026），别人通过用户名找到你，但永远看不到你的手机号。你甚至可以选择不让已保存联系人看到你的手机号。

怎么开： Signal 设置 → 头像旁的编辑按钮 → 用户名 → 设置你的用户名

建议： 尽快设置。如果你不设置，你的手机号仍然是对外可见的。设置了之后，只有你主动分享手机号的人才能看到。

5. 屏幕截图提醒：知道谁在截屏

这个功能在 2024 年下半年加入 Signal，很多人还不知道。

开启后： 当你在 Signal 对话中截图时，对方会收到一条系统通知：“XX 在对话中截取了屏幕”。这不是"禁止截图"（安卓上很难做到），而是"通知对方"。

为什么有用： 很多隐私泄露发生在对方偷偷截图。这个功能让你至少知道自己的消息被截了图。

怎么开： Signal 设置 → 隐私 → 开启"在对话中截取屏幕时发送通知"

局限： 只对 Signal 内的对话有效。如果你用的是安卓的系统截图快捷键，有时可能绕过这个提醒。iPhone 上的效果更稳定。

6. 中继调用：隐藏你的真实手机号

当你给别人打电话时，你的手机号会显示在对方的来电显示上。Signal 的中继调用可以改变这一点。

开启后： Signal 会通过一个中继服务器连接你和对方，对方看到的是一个随机号码，不是你的真实手机号。

怎么开： Signal 设置 → 高级 → 中继调用 → 开启

代价： 中继调用的通话质量可能比直接拨打略差，偶尔会有延迟。如果你在国内使用且网络不稳定，建议只在对隐私要求高的通话中开启。

7. 只允许联系人添加：拒绝陌生人消息

Signal 默认允许任何人给你发送消息（只要他们知道你的手机号或用户名）。如果你经常收到陌生人消息，可以改成只允许通讯录中的联系人。

怎么开： Signal 设置 → 隐私 → 消息请求 → 选择"已知联系人"

建议： 如果你用 Signal 主要和特定人群（家人、朋友）聊天，开启这个选项。如果你用 Signal 做公开联系（比如社交媒体上分享用户名），就保持默认。

8. 禁用链接预览：防止数据泄露

当你在 Signal 中发送一个链接时，Signal 会默认生成一个预览（显示网页标题和缩略图）。这个功能需要 Signal 向目标网站请求数据。

风险： 目标网站的服务器会记录这次请求，包括你的 IP 地址和请求时间。虽然 Signal 不会告诉网站你是谁，但网站知道有人（从某个 IP）在 Signal 里分享了这个链接。

怎么关： Signal 设置 → 隐私 → 关闭"生成链接预览"

建议： 发送普通链接（新闻、文章）不用关。但发送敏感链接（网盘、私密内容）时建议关闭。

9. 关闭已读回执和在线状态

Signal 默认会告诉对方你已读消息以及你的在线状态。对于大多数日常聊天这很方便，但在某些场景下你可能不希望对方知道。

怎么关：

  • 已读回执：Signal 设置 → 隐私 → 关闭"已读回执"
  • 在线状态：Signal 设置 → 隐私 → 关闭"显示在线状态"

注意： 关闭后你也看不到对方的已读回执和在线状态。这是双向的，Signal 不允许"自己看不到别人的但别人能看到我的"这种设置。

设置优先级建议

如果你不想一个一个看，这里是我推荐的优先级排序：

优先级设置理由
必开注册锁防 SIM 卡劫持，一旦被攻击损失巨大
必开用户名隐藏手机号，从根本上保护身份
必开消失消息即使手机丢了，消息也不会泄露
建议开屏幕安全锁防止身边人偷看
建议开截屏提醒知道谁在截屏你的对话
按需开中继调用打电话时隐藏号码
按需开禁用链接预览分享敏感链接时开启
按需开只允许联系人经常收到陌生人消息时开启
可选关闭已读回执不想被别人知道你看了消息

如果你把这 9 个设置全部开启，Signal 的隐私保护已经接近最强状态了。剩下的安全就取决于你的使用习惯——比如不在不安全的 Wi-Fi 下处理敏感信息、定期更新 App 版本、不把 PIN 写在容易被看到的地方。

想了解更多 Signal 的加密原理，可以看我们的 Signal 端到端加密详解。如果你还在犹豫用不用 Signal，Signal 和微信的安全性对比可能会帮你做决定。

常见问题

Signal 的注册锁 PIN 忘了怎么办？

如果你忘记了注册锁 PIN，唯一的办法是等待 7 天的冷却期后再重新注册。在此期间，你的旧账号仍然可以正常使用。7 天后旧账号会自动注销，你可以用同一个手机号注册新账号，但所有聊天记录会丢失。所以务必把 PIN 存在密码管理器里。

消失消息能被恢复吗？

不能。Signal 的消失消息在计时器到期后会在本地设备上被永久删除，且没有"最近删除"功能。删除后即使在 Signal 的服务器端（如果有的话）也找不到。这是 Signal 的设计原则——真正的消失。

屏幕安全锁会被强制破解吗？

理论上，如果有人获取了你手机的全盘加密密钥（比如通过物理提取），屏幕安全锁可以被绕过。但在日常生活中，屏幕锁足以防止同事、家人或临时接触手机的人偷看你的 Signal 消息。

中继调用对通话质量有多大影响？

在国内使用时，中继调用会通过海外服务器中转，通话延迟可能增加 100-300ms。日常语音通话影响不大，但视频通话可能会有明显的画面卡顿。如果网络不稳定，建议重要通话不要开中继。

关闭已读回执后对方真的完全看不到吗？

是的，关闭已读回执后，对方只能看到消息"已送达"（两个灰勾），看不到"已读"（两个蓝勾）。而且因为这是双向设置，你也看不到对方的已读状态。Signal 不支持单方面关闭——要么双方都看不到，要么双方都能看到。
