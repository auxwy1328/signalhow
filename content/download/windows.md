## Signal Windows 版下载

Signal 桌面版支持 Windows 10（64-bit）及以上系统，让你可以在电脑上方便地使用 Signal。

## 下载与安装

1. 访问 signal.org 下载 Windows 安装包
2. 运行下载的 `.exe` 安装程序
3. 按提示完成安装
4. 打开 Signal 桌面版，扫描手机上的二维码关联设备

## 关联手机

桌面版需要先在手机上安装 Signal 并完成注册。关联步骤：

1. 手机打开 Signal → 设置 → 关联设备
2. 点击"关联新设备"
3. 用手机扫描电脑上的二维码
4. 等待同步完成

## 系统要求

- Windows 10 64-bit 或更高版本
- 64 位处理器
- 约 200MB 磁盘空间

{{< callout type="info" title="独立模式" >}}
Signal 最新版本支持独立桌面使用，不再需要手机在线即可收发消息。首次关联手机后，桌面版可以独立工作。
{{< /callout >}}
