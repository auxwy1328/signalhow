完成 Signal 注册后，建议立即进行以下隐私和安全设置，最大化保护你的通讯隐私。

## 1. 关闭已读回执

已读回执会让对方知道你已经阅读了消息。如果你不想暴露这个信息：

**设置 → 隐私 → 已读回执 → 关闭**

关闭后，你也不会看到对方是否已读你的消息（对称设置）。

## 2. 关闭输入指示器

输入指示器会显示"正在输入…"，让消息的实时性暴露。

**设置 → 隐私 → 输入指示器 → 关闭**

## 3. 关闭链接预览

链接预览会在聊天中显示链接的缩略图和标题。这会暴露你在聊什么内容。

**设置 → 隐私 → 链接预览 → 关闭**

{{< callout type="info" title="为什么关闭链接预览？" >}}
链接预览需要 Signal 向目标网站请求内容，这会泄露你在聊天的上下文信息。关闭后链接仍然可以点击打开，只是不会在聊天中显示预览。
{{< /callout >}}

## 4. 启用信号 PIN

Signal PIN 用于账户恢复和安全验证。

**设置 → 账户 → 信号 PIN → 启用**

建议设置一个你能记住但不容易被猜到的 PIN。

## 5. 设置应用锁

防止他人在你不在时打开 Signal 查看消息。

**设置 → 隐私 → 应用锁 → 启用**

支持指纹、面容或系统密码锁定。

## 6. 验证安全号码

与重要联系人交换密钥指纹，确保通讯没有被中间人攻击。

**打开与联系人的聊天 → 点击联系人名称 → 查看安全号码 → 与对方对比验证**

## 7. 启用消失消息

在重要对话中启用消息自动销毁。

**打开聊天 → 点击联系人名称 → 消失消息 → 设置时间**

建议设置为 1 天或 1 周。

## 8. 配置通知设置

减少不必要的通知暴露：

**设置 → 通知 → 按需调整**

- 关闭消息预览（不显示通知中的消息内容）
- 设置通知优先级

{{< callout type="success" title="设置完成！" >}}
完成以上设置后，你的 Signal 已经达到了较高的隐私保护水平。这些设置可以根据你的使用习惯随时调整。
{{< /callout >}}
