完成 [Signal 注册](/guides/registration/) 后，建议立即进行以下隐私和安全设置。Signal 的默认设置虽然已经比大多数通讯应用更安全，但通过以下几项调整，你可以将隐私保护提升到最高水平。[Signal Foundation](https://signal.org/) 官方也推荐用户根据自身需求调整隐私设置。

{{< callout type="info" title="为什么要调整这些设置？" >}}
Signal 的默认设置在安全性和易用性之间做了平衡。关闭一些便利功能（如已读回执、链接预览）可以显著减少你暴露给对方和平台的信息量。根据你的实际需求选择调整。
{{< /callout >}}

## 1. 关闭已读回执

**路径：设置 → 隐私 → 已读回执 → 关闭**

已读回执让发送者知道你已阅读了他们的消息（显示蓝色双勾）。关闭后，发送者只能看到消息已送达（灰色双勾），但不知道你是否已读。

**需要注意**：已读回执是**对称设置**，关闭后你也无法看到别人是否已读你的消息。如果你经常需要确认对方是否已读消息，可以保持开启。

## 2. 关闭输入指示器

**路径：设置 → 隐私 → 输入指示器 → 关闭**

输入指示器会在你打字时向对方显示"正在输入…"的提示。这会暴露你的实时状态——对方能知道你正在回复他们，甚至能推测你的回复速度和犹豫程度。

关闭后，你的打字动作不会被对方感知，你可以从容地思考和编写回复。

## 3. 关闭链接预览

**路径：设置 → 隐私 → 链接预览 → 关闭**

这是最容易忽略但很重要的一个设置。链接预览会在聊天中自动显示你发送的链接的网页缩略图和标题。

**关闭链接预览的理由：**
- Signal 需要向目标网站请求内容才能生成预览，这会泄露你在讨论什么话题
- 预览的缩略图可能包含你不想让聊天对象看到的敏感内容
- 即使你发送的链接是公开的，预览也会暴露你的浏览上下文

关闭后，链接仍然可以正常点击和打开，只是在聊天界面中不会自动生成预览卡片。

## 4. 启用信号 PIN

**路径：设置 → 账户 → 信号 PIN → 启用**

信号 PIN 是一个 4 位数以上的个人识别码，有两个重要用途：

1. **账户恢复**：如果你长时间未使用 Signal 或更换了设备，PIN 可以帮助你恢复账户
2. **注册锁**：启用注册锁后，即使有人获取了你的手机号和验证码，也需要输入 PIN 才能注册新账号，有效防止 SIM 卡劫持攻击

![Signal PIN 码锁屏设置](/images/guides/setup/pin-lock.jpg)

**设置建议**：选择一个你能记住但不容易被猜到的 PIN（不要用 1234、0000 等常见组合）。不要和手机锁屏密码相同。

## 5. 设置应用锁

![Signal 隐私设置对比](/images/guides/setup/privacy-settings.jpg)

**路径：设置 → 隐私 → 应用锁 → 启用**

应用锁可以在你每次打开 Signal 时要求进行身份验证，防止他人在你不在时偷看你的消息。

**支持的锁定方式：**
- **生物识别**：指纹解锁（Android）或面容 ID（iPhone），最方便
- **系统密码**：使用手机的锁屏密码

启用后，即使你把手机临时放在桌上，别人也无法直接打开 Signal 查看你的聊天内容。

## 6. 启用消失消息

![Signal 消息自动消失设置](/images/guides/setup/disappearing-messages.jpg)

**路径：设置 → 隐私 → 默认定时消息 → 选择时间**

这项设置为所有新对话设置默认的消息自动消失时间。你还可以在每个单独的聊天中覆盖此设置。

**可选时间范围**：5 秒、10 秒、30 秒、1 分钟、5 分钟、30 分钟、1 小时、12 小时、1 天、1 周、4 周

**设置建议**：对于普通用户，建议设置为 **1 周或 4 周**。这样既能保护隐私（旧消息自动删除），又不会因为消息消失太快影响日常使用。更详细的教程请参考 [Signal 阅后即焚设置教程](/guides/disappearing-messages/)。

## 7. 验证安全号码

**路径：打开与联系人的聊天 → 点击联系人名称 → 查看安全号码**

安全号码（Safety Number）是一组数字指纹，用于验证你与联系人的端对端加密是否安全。如果安全号码发生变化，可能意味着存在中间人攻击。

**验证方法：**
- **面对面验证**：与对方当面对比各自手机上显示的安全号码数字
- **QR 码验证**：让对方向你展示 QR 码，或者你展示 QR 码让对方扫描
- **远程验证**：通过其他安全渠道（如电话）对比数字

建议至少与重要的联系人（家人、商业伙伴）完成一次安全号码验证。详细了解请阅读 [Signal 安全号码验证教程](/guides/safety-number/)。

## 8. 配置通知隐私

**路径：设置 → 通知 → 自定义**

减少通知带来的隐私泄露：

- **关闭消息预览**：通知中不显示消息内容，只显示"1 条新消息"
- **按联系人自定义通知**：为重要联系人设置独特的通知音效，方便区分

{{< callout type="success" title="设置完成！" >}}
完成以上 8 项设置后，你的 Signal 已经达到了极高的隐私保护水平。这些设置并非一成不变——你可以根据实际使用情况随时调整。如果后续需要在新设备上使用 Signal，可以参考 [Signal 桌面版关联手机教程](/guides/desktop-link/) 进行设备管理。
{{< /callout >}}

## 常见问题

### 这些设置会影响 Signal 的正常使用吗？

不会影响核心功能。关闭已读回执和输入指示器只是让对方看不到你的在线状态，关闭链接预览只是不自动显示网页缩略图，消息仍然可以正常收发。这些设置牺牲的是一些"便利性"，换来的是更高的隐私保护。

### 可以只关闭部分设置吗？

当然可以。如果你觉得某些设置太激进（比如关闭已读回执），可以只调整你关心的部分。建议至少启用 **信号 PIN**、**应用锁** 和 **消失消息** 这三项，它们对日常使用几乎无影响，但能显著提升安全性。

### 更新 Signal 后设置会丢失吗？

不会。所有这些设置都保存在你的本地设备和 Signal 的加密存储中，应用更新不会影响你的设置。但如果你卸载并重新安装 Signal，需要重新配置。

### 信号 PIN 和应用锁有什么区别？

信号 PIN 主要用于**账户恢复和防劫持**，在注册新设备或恢复账户时需要输入。应用锁则是在每次**打开应用时**要求身份验证，防止他人偷看消息。两者互补，建议同时启用。
