Signal 的群聊和微信、Telegram 很不一样——它默认端到端加密，不需要额外设置。但这也带来了一些使用上的特殊性：群成员上限不同、管理员权限不同、邀请机制不同。

如果你习惯了 Telegram 或微信的群管理逻辑，切换到 Signal 会有一些"原来不一样"的地方。这篇把 Signal 群组的创建、管理和隐私保护讲透。

## 一、创建 Signal 群组

### 基本创建

1. 打开 Signal，点击右上角铅笔图标（新消息）
2. 选择"新建群组"
3. 从联系人列表中勾选要邀请的成员
4. 点击"下一步"，输入群名称和群头像
5. 点击"创建"

### 首次打招呼

创建群组后，Signal 会自动在群中发送一条系统消息："XX 创建了群组"。你可以紧接着发送第一条欢迎消息，新成员加入时也会显示系统通知。

### 群名称和头像

群名称和头像对所有人可见。建议：
- 群名称简洁明确（不超过30字）
- 头像选与群主题相关的图片
- 修改群名称/头像后所有成员都会收到通知

## 二、群管理员功能

### 设置管理员

群设置→群管理员→添加管理员。只有创建者和已有管理员可以设置新管理员。

### 管理员能做什么

| 权限 | 说明 |
|------|------|
| 修改群名称和头像 | 所有成员可见变更记录 |
| 添加/移除成员 | 移除后该成员无法看到新消息 |
| 设置消息自动删除 | 可选1天到1个月 |
| 管理群组链接 | 开启/关闭/重置链接 |
| 审批加入请求 | 如果开启了加入审批 |

### 管理员不能做什么（和Telegram的区别）

| Telegram管理员可以 | Signal管理员不能 |
|------------------|----------------|
| 禁言特定成员 | ❌ 不支持 |
| 限制发送媒体文件 | ❌ 不支持 |
| 设置慢速模式 | ❌ 不支持 |
| 设置管理员别名 | ❌ 不支持 |
| 查看消息编辑历史 | ❌ 不支持 |

Signal 的管理员权限设计偏保守——防止滥用权限也意味着管理灵活性不如 Telegram。如果你的群需要精细化管理（禁言、审核新成员发言等），Signal 可能不适合大型社群运营。

## 三、邀请成员的方式

### 方式 1：直接添加

群聊→点击顶部群名称→添加成员→从联系人中选择

**限制：** 只能添加通讯录中已有 Signal 账号的联系人

### 方式 2：群组链接

群设置→群链接→开启

开启后生成一个链接，分享给任何人即可加入。Signal 群链接的特点：
- 链接可以被关闭和重置（重置后旧链接失效）
- 开启链接后任何人点击链接即可加入（不需要管理员审批）
- 建议定期重置链接防止链接泄露

### 方式 3：群组二维码

群设置→群链接→分享二维码

二维码和群链接实际上是同一个功能的不同入口，扫码等于点链接。

### 注意安全和隐私

- 群链接不要公开发布（如社交媒体），否则陌生人可能涌入
- 如果群中出现异常成员，立即重置群链接
- 建议开启"加入请求审批"（如果有敏感讨论）

## 四、群隐私与安全设置

### 消息自动删除

群设置→消息自动删除→选择时间。

设置为自动删除后，所有新发送的消息会在指定时间后从所有人的设备上自动删除。这对降低信息泄露风险很有帮助——即使某个成员的设备被查，历史消息也已经在自动删除机制下消失了。

### 群安全锁

Signal 的每一个群聊都有一个"群安全锁"（Group Safety Number），可以验证群聊没有被中间人攻击。

操作方法：群设置→查看群安全号码→与其他成员当面或通过安全渠道对比这个号码。

### 退群与防骚扰

如果离开群组：
- 其他成员会看到"XX 离开了群组"的通知
- 你无法再看到离开后的新消息
- 你发送的历史消息仍保留在群中（Signal 不会删除）

如果群聊中有骚扰成员：
- 点进该成员资料→屏蔽→该成员无法再私信你
- 群管理员可以将其移出群组
- Signal 没有"禁止被拉群"功能，但可以屏蔽反复拉你进群的人

## 五、群聊实用技巧

| 技巧 | 操作 |
|------|------|
| @所有人 | 在输入框中输入@，选择"所有人"发送群通知 |
| @特定成员 | 输入@后选择具体成员名 |
| 引用回复 | 长按消息→回复→输入回复内容 |
| 搜索群聊记录 | 群设置→群内搜索 |
| 查看媒体文件 | 群设置→查看所有媒体 |
| 群语音/视频通话 | 群聊右上角电话/视频图标 |

## 六、Signal 群组 vs WhatsApp vs Telegram群组

| 特性 | Signal群 | WhatsApp群 | Telegram群 |
|------|---------|-----------|-----------|
| 默认加密 | ✅ 端到端 | ✅ 端到端 | ❌ 仅私密聊天 |
| 群成员上限 | 1000人 | 1024人 | 20万人 |
| 管理员禁言 | ❌ | ❌ | ✅ |
| 群组链接 | ✅ | ✅ | ✅ |
| 消息自动删除 | ✅ | ✅ (Disappearing) | ✅ |
| 群公告 | ❌ | ✅ | ✅ |
| 群文件共享 | 支持 | 支持（100MB） | 支持（2GB） |

Signal 群组最适合注重隐私的中小型群体——家庭、密友、亲密团队。如果你需要运营大型社群（几百上千人），Telegram 是目前唯一支持精细权限管理的端到端加密替代方案（但需要手动开启私密聊天）。

对于绝大多数日常群聊场景，Signal 群组的1000人上限和基本管理功能已经足够。它的优势不在于功能多，而在于"默认安全"——不需要任何额外设置，所有群聊内容就是端到端加密的。
