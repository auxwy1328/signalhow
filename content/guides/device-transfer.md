## 前言

换手机是使用 Signal 过程中最常见的场景之一。幸运的是，Signal 提供了完善的设备迁移功能，可以将所有聊天记录、媒体文件和设置完整转移到新设备。

## 方法一：Signal 官方迁移工具

Signal 从 v6.0 开始内置了设备迁移功能，这是最简单的迁移方式。

### 从旧 Android 到新 Android

1. 在旧手机上打开 Signal，进入 **设置 → 聊天 → 迁移账户**
2. 选择 **"从此设备迁移"**
3. 新手机安装 Signal 后打开，选择 **"从其他设备迁移"**
4. 两台手机连接同一个 Wi-Fi 网络
5. 用旧手机扫描新手机上的二维码
6. 等待迁移完成，不要中途关闭应用

### 从旧 iPhone 到新 iPhone

1. 确保两台 iPhone 已更新到最新版 iOS
2. 在旧 iPhone 上打开 Signal → 设置 → 聊天 → 迁移账户
3. 选择从此设备迁移，等待生成迁移代码
4. 在新 iPhone 上安装 Signal，打开后选择从其他设备迁移
5. 输入旧手机显示的迁移代码
6. 等待迁移完成

## 方法二：手动备份与恢复

如果官方迁移工具不可用，可以使用 Signal 的本地备份功能。

### Android 备份步骤

1. 打开 Signal → 设置 → 聊天 → 聊天备份
2. 开启 **"创建备份"** 并设置备份频率
3. Signal 会将加密备份保存到本地存储
4. 将备份文件（`signal_backup Key` 和备份文件夹）复制到新手机
5. 在新手机上安装 Signal，注册同一个手机号
6. Signal 会自动检测到备份文件并提示恢复

### iOS 备份步骤

iOS 版 Signal 的备份通过 iCloud 完成：

1. 打开 Signal → 设置 → 聊天 → 聊天备份
2. 开启 **iCloud 备份**
3. 在新 iPhone 上安装 Signal 并注册同一号码
4. Signal 会自动从 iCloud 恢复备份

## 跨平台迁移

从 Android 迁移到 iPhone（或反过来）比较复杂，因为两个平台的加密方式不同。目前 Signal 不直接支持跨平台迁移，建议使用以下方法：

- **Android → iPhone**：手动导出重要聊天记录截图，在新设备重新开始
- **iPhone → Android**：同样需要手动处理，无法直接传输加密消息

## 迁移常见问题

**Q：迁移需要多长时间？**
取决于聊天记录数量和媒体文件大小。一般 10GB 数据大约需要 10-30 分钟。

**Q：迁移过程中断怎么办？**
重新开始迁移过程即可，Signal 支持断点续传。

**Q：旧手机上的数据会保留吗？**
迁移完成后，旧手机上的数据不会被自动删除。你可以手动清除。

**Q：迁移失败怎么办？**
确保两台手机在同一个 Wi-Fi 网络、Signal 是最新版本、手机存储空间充足。
