Signal 的群组功能支持端对端加密保护，每个群组成员之间的所有消息都经过加密传输。与普通一对一聊天一样，Signal 群组中的消息对服务器完全不可读。本文详细介绍 Signal 群组的创建、设置和管理方法，帮助你高效使用群组功能。

## Signal 群组加密原理

Signal 群组采用 **Sender Keys** 机制来实现高效的多端对端加密通讯，这是 Signal Protocol 中专门为群组场景设计的加密方案：

- 每个群组成员生成并持有一个独立的 Sender Key
- 当成员发送消息时，使用自己的 Sender Key 加密消息一次，所有群成员使用同一把 Sender Key 解密
- 这种设计使得发送一条群消息只需要一次加密操作，而非为每个群成员分别加密一次，大幅提升了群组通讯的效率
- 每当有新成员加入或现有成员离开群组时，所有成员的 Sender Key 自动轮换更新，确保新成员无法查看加入之前的历史消息，离开的成员也无法继续读取后续消息

这种设计在保证端对端加密安全性的同时，实现了高效的多方通讯。想深入了解加密技术细节可以参考 [Signal 加密原理详解](/safety/encryption/)。

## 创建群组
![创建 Signal 群组](/images/guides/group-chat/body1.jpg)


### 在 Android 上创建群组

1. 打开 Signal 应用，点击右下角的 **蓝色铅笔图标**
2. 在弹出的菜单中选择 **新建群组**
3. 从你的 Signal 联系人列表中勾选要添加的成员（支持多选）
4. 点击右下角的箭头图标进入下一步
5. 输入 **群组名称**：建议使用清晰有意义的名称，方便成员识别
6. 可选择设置 **群组头像**：点击头像区域从相册选择图片
7. 点击右上角的 **创建** 按钮完成

### 在 iOS 上创建群组

1. 打开 Signal 应用，点击右上角的 **编辑图标**（或向左滑动屏幕）
2. 选择 **新建群组**
3. 从联系人列表中选择要邀请的成员
4. 点击 **下一步**
5. 设置群组名称和群组头像
6. 点击 **创建** 确认

群组创建后，所有被邀请的成员会收到群组创建通知，且群组中已经可以使用端对端加密通讯。

## 群组设置详解

点击群组顶部的群组名称可以进入群组设置页面，这里提供了丰富的管理选项：

### 基本信息设置

- **群组名称**：随时可以修改，群名修改后所有成员都能看到更新
- **群组头像**：设置群组图标，建议使用与群组主题相关的图片
- **群组链接**：生成可分享的邀请链接，方便快速邀请大量成员加入

### 成员权限管理

- **添加成员**：点击「添加成员」从 Signal 联系人中选择新成员
- **移除成员**：点击成员名称旁的选项，选择「从群组移除」
- **设为管理员**：可以将其他成员提升为管理员，赋予他们管理群组的权限
- **成员角色**：管理员拥有添加/移除成员、修改群组设置、批准入群申请等权限

### 消息控制选项

- **消息自动消失计时器**：可以为整个群组设置统一的自动消失时间，详细设置方法参考 [Signal 消息消失教程](/guides/disappearing-messages/)
- **仅管理员可发送消息**：开启后只有管理员可以在群组中发言，其他成员只能阅读——适用于公告通知类群组
- **编辑群组消息**：开启后群成员可以编辑自己已发送的消息（限时 24 小时内）

## 群组链接分享
![群组链接分享设置](/images/guides/group-chat/body2.jpg)


群组链接是 Signal 提供的高效邀请方式，特别适合需要邀请大量成员的场景，比如社区活动群、兴趣小组或公司内部群：

### 生成和分享群组链接

1. 进入群组设置页面
2. 点击 **群组链接** 选项
3. 开启 **群组链接** 开关
4. 系统会生成一个类似 `https://signal.group/#xxxxx` 的链接
5. 点击 **分享** 通过任意渠道发送链接（微信、邮件、短信、二维码等）

### 群组链接安全注意事项

- **链接即邀请凭证**：任何获得此链接的人都可以直接加入群组，请务必控制链接的传播范围
- **随时可重置**：如果链接泄露或不再需要，可以在群组链接设置中点击「重置链接」，旧链接立即失效
- **审批机制**：可以开启「管理员审批」功能，通过链接申请加入的人需要管理员手动批准才能入群
- **链接有效期限**：设置链接过期时间，到期后自动失效

## 群组实用功能

### 投票功能

Signal 内置了群组投票功能，方便快速收集成员意见和做出集体决策：

1. 在群组聊天输入框旁点击 **附件图标（+）**
2. 在弹出的菜单中选择 **投票**
3. 输入投票的 **问题**（例如「下周团建去哪里？」）
4. 添加投票 **选项**（支持添加多个选项）
5. 可选择是否允许多选
6. 点击发送，群组成员即可开始投票

投票完成后可以查看每个选项的得票数和投票成员列表。投票功能非常适合活动安排、餐厅选择、时间协调等需要集体决策的场景。

### @提及功能

在群组中需要提醒特定成员时：

- 输入 **@** 符号后会自动弹出成员列表，选择目标成员即可
- 被提及的成员会收到特殊的推送通知，确保不会错过重要消息
- 管理员可以使用 **@everyone** 提醒群组中的全部成员（所有成员都会收到通知）
- 适用于需要特定人关注的消息，如任务分配、紧急通知等

### 表情回应和反应

对群组消息快速表达态度而无需发送额外文字：

- **长按**任意消息，会弹出表情选择面板
- 点击对应的表情即可添加反应（如 👍、❤️、😂 等）
- 多个成员可以对同一条消息添加不同反应
- 点击已有反应可以查看具体哪些成员添加了该反应

### 媒体共享和文件传输

Signal 群组支持完整的媒体和文件功能：

- **发送图片和视频**：支持拍摄或从相册选择，最高支持 100MB 单文件
- **文件传输**：可发送 PDF、文档、压缩包等任意类型文件
- **语音消息**：长按麦克风按钮录制语音消息
- **位置分享**：发送实时位置或选择一个地点分享
- **联系人卡片**：在群组中分享 Signal 联系人的名片

点击群组设置中的 **媒体** 选项可以集中浏览该群组中所有共享的图片和视频文件。

## 群组管理最佳实践
![群组管理最佳实践](/images/guides/group-chat/body3.jpg)


### 管理大型群组的建议

Signal 群组最多支持 **1000 名成员**。当群组规模增大时，建议采取以下管理策略：

- **设置多名管理员**：分担日常管理工作，避免单一管理员缺席时群组无人管理
- **开启仅管理员发消息**：对于信息发布类群组，限制发送权限可以有效减少无关信息干扰
- **设置消息消失**：开启自动消失功能减少长期积累的数据量，参考 [消息消失教程](/guides/disappearing-messages/)
- **定期清理成员**：移除长期不活跃的成员，保持群组活力
- **利用群组链接和审批**：替代逐个添加成员的繁琐流程，同时通过审批机制控制入群质量

### 群组安全建议

为了确保群组通讯的安全性和隐私保护，建议遵循以下实践：

- **不要在群组中分享敏感个人信息**：如身份证号、银行卡号、密码等，群组成员人数越多信息泄露风险越高
- **谨慎分享群组链接**：群组链接一旦公开，任何人都可以加入。建议使用管理员审批机制作为额外保障
- **定期检查成员列表**：确认没有被未经授权的人员加入群组
- **为新成员开启独立计时器**：对于敏感群组，可以考虑在每次有成员变动时重置消息消失计时器

## 常见问题

### Signal 群组最多能有多少人？

Signal 群组目前最多支持 1000 名成员。如果你的需求超过这个限制，可以考虑使用 Signal 的「社区」功能（Communities）。社区可以将多个相关群组组织在一起，适合大型组织或兴趣社区使用。每个社区可以包含多个群组和公告频道。

### 新加入的群成员能看到加入前的历史消息吗？

不能。这是 Signal 群组加密机制（Sender Keys）的安全设计——当新成员加入群组时，系统自动为所有成员轮换更新加密密钥。新成员获得的是全新的密钥，无法解密加入之前发送的任何消息。这与 Signal 一贯的隐私保护原则完全一致：你只应该看到你参与期间的信息。

### 如何把群主身份转交给其他人？

Signal 目前没有直接的「群主转让」功能，但你可以通过设置多名管理员来实现类似效果。管理员拥有添加移除成员、修改群组设置、管理群组链接等几乎所有管理权限。建议在创建群组时就指定 2-3 名管理员，避免单人管理导致的单点故障。

### 群组消息会占用多少手机存储空间？

群组中的所有媒体文件（图片、视频、文件）都会下载并保存在本地存储中。活跃群组的存储占用可能增长很快。你可以进入群组设置查看该群组的存储占用，并在「媒体」页面中批量选择和删除不需要的文件。如果整体存储空间紧张，可以参考 [Signal 备份教程](/guides/backup/) 了解如何管理备份数据。

### 群组成员能看到我的手机号码吗？

不能。Signal 群组中的成员只能看到你在 Signal 中设置的 **用户名和头像**，你的手机号码不会直接显示给其他群成员。这是 Signal 隐私保护设计的一部分。关于 Signal 注册和隐私设置的更多内容，请参考 [Signal 注册完整教程](/guides/registration/)。
