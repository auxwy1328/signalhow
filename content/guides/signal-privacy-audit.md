Signal 号称是最安全的即时通讯软件，这一点在加密技术层面确实成立。但软件安全和使用安全是两回事——一辆防弹车如果你不锁车门，照样会被偷。

这篇清单用8个步骤逐一排查你的 Signal 账号隐私漏洞，每个步骤都附带具体的检查方法和加固措施。跟着做一遍，大约需要10分钟。

我帮朋友做过一次完整的 Signal 隐私审计，发现他的账号存在至少3个明显漏洞——手机号对所有人生效、一台两年前换掉的旧手机仍然关联着他的账号、链接预览完全没关。他说从来没想过这些。这篇文章就是那次审计的完整方法论。

## 第1步：检查手机号暴露范围

这是最容易被忽视也是影响最大的隐私风险。

**检查方法**：

打开 Signal → 左上角头像 → 设置 → 隐私 → **通过手机号发现我**

这里有三个选项：
- 所有人（Anyone）
- 我的联系人（My Contacts）
- 没有人（Nobody）

**风险评估**：

如果你的设置是"所有人"，意味着任何知道你手机号的人都可以在 Signal 中找到你的账号。这包括前同事、快递员、网约车司机——任何你给过手机号的人。对于大多数用户来说，这个范围远远大于你希望暴露 Signal 身份的人群。

**加固方案**：

设置为"我的联系人"或"没有人"。设置为"没有人"意味着即使有人有你的手机号，也无法在 Signal 中找到你——他们只能通过你主动分享的用户名来添加你。这是最高级别的手机号保护。

但需要注意：设置为"没有人"后，你的现有联系人中不在你 Signal 通讯录里的人也无法通过手机号找到你。如果你经常需要别人通过手机号加你，可以设为"我的联系人"作为折中方案。

**额外检查**：你是否曾在以下场景中暴露过 Signal 绑定的手机号？
- 在社交媒体账号上绑定了同一手机号
- 在群聊中通过手机号分享邀请
- 在个人签名或名片上印了手机号
- 在外卖、快递等平台使用了同一手机号

如果以上任何一条为"是"，你的手机号和 Signal 账号的关联可能已经超出你的预期。

## 第2步：检查已关联设备列表

Signal 支持最多5台设备同时关联。但很多用户换手机后忘记断开旧设备，形成了严重的安全隐患。

**检查方法**：

打开 Signal → 左上角头像 → 设置 → **已关联的设备**

列表中会显示所有已关联的设备名称和最后活动时间。

**风险评估**：

仔细检查每一台设备。有没有你不认识的设备名称？有没有你去年换掉的旧手机？有没有你在公共电脑上临时登录过但忘记断开的桌面版？任何一台你不控制的设备都意味着你的全部聊天记录可能被读取。

**加固方案**：

不认识的设备立即断开。旧手机、旧电脑上的 Signal 实例全部断开。

断开方法：点击设备名称右侧的编辑按钮 → 选择"断开关联"

断开后，该设备上的所有本地数据会被清除。但要注意：如果对方已经屏幕截图或拍照记录了聊天内容，断开设备关联并不能删除对方已经复制的数据。但至少对方无法再读取你的新消息，也无法向其他人发送伪造的消息。如果需要重新关联，需要重新扫码验证。

**建议频率**：每月检查一次已关联设备列表。这是 Signal 最基础也最重要的安全维护操作。[Signal 桌面版关联手机教程](/guides/desktop-link/) 有详细的关联操作说明。

## 第3步：关闭链接预览

链接预览是 Signal 的便利功能，但也是隐私泄露的隐蔽通道。

**检查方法**：

打开 Signal → 左上角头像 → 设置 → 隐私 → 找到 **链接预览** 选项

**风险评估**：

当链接预览启用时，你在聊天中发送的每个链接，Signal 都会访问该链接获取标题和缩略图。这意味着：

- 链接指向的网站服务器会收到一个来自你的 IP 地址的请求
- 网站可以通过分析请求的 User-Agent 知道有人用 Signal 访问了该链接
- 如果你发送的是社交媒体链接（微博、Twitter、Instagram），平台可以关联你的 Signal 使用行为和你可能关联的社交媒体账号

对于普通网页链接，风险较低。但如果你经常发送包含个人信息的链接（比如一个在线文档、一个相册链接），链接预览可能会暴露你的浏览习惯。

**加固方案**：

关闭链接预览。在设置中取消勾选"自动链接预览"选项。关闭后，发送链接时不会自动生成预览卡片，你仍然可以在需要时手动点击链接预览来启用（仅限单条消息）。

这是一个影响体验但能显著提升隐私的选择。实际使用中，关闭链接预览后你会发现聊天中的链接变成了纯文字，不再有缩略图和标题卡片。这可能需要几天适应。如果你和朋友经常分享链接并希望对方能快速了解链接内容，可以在发送具体链接时手动点击链接来生成单次预览——这样既不会自动暴露你的浏览行为，又能让对方看到预览。如果你经常在 Signal 中分享链接，可以先关闭一段时间观察是否影响日常使用，再决定是否长期关闭。

## 第4步：检查已读回执和输入指示器

已读回执（read receipts）告诉对方你已经看了消息。输入指示器（typing indicators）告诉对方你正在打字。这两个功能很方便，但它们会向对方透露你的实时状态。

**检查方法**：

打开 Signal → 左上角头像 → 设置 → 隐私 → 找到 **已读回执** 和 **输入指示器**

**风险评估**：

已读回执会让对方知道你什么时候看了消息。这意味着：
- 你无法使用"没看到消息"作为延迟回复的理由
- 对方可以判断你的在线时间模式
- 在敏感沟通场景中，已读回执可能被用来施压（"你明明已经看了为什么还不回"）

输入指示器更细粒度——对方可以在你打字时看到"正在输入..."提示。这会暴露你当前正在使用 Signal、你对消息有回应意愿等行为信息。

**加固方案**：

关闭已读回据和输入指示器。关闭后你仍然可以看到对方的已读状态（除非对方也关闭了），这实际上给你了一个信息优势。关闭后你的消息发送不会被对方看到任何状态反馈。

对于工作场景中的 Signal 使用，建议至少关闭输入指示器。我的习惯是关闭已读回据但保留输入指示器——这样对方知道我在线但不知道我是否已读了消息。这种配置在非正式沟通中很实用。在工作场景下，如果你和同事用 Signal 沟通，关闭已读回据可以避免同事在休息时间发消息后期待你回复的压力。在私人关系中，关闭两者可以让沟通更加自由——你可以在忠实复后再处理消息，同时对方不会觉得你无视了他们。——这样可以避免在犹豫如何回复时让对方知道你在场。已读回据是否关闭取决于你和沟通对象的关系。

## 第5步：验证 disappearing messages 设置

Disappearing messages（消失消息）是 Signal 的核心隐私功能，但很多用户的设置存在漏洞。

**检查方法**：

打开任意一个聊天 → 点击聊天名称 → **消失消息计时器**

**常见漏洞**：

1. **设置了计时器但只针对个别聊天**：消失消息是按聊天设置的，不是全局设置。你可能以为所有聊天都设置了7天消失，但实际上只有最近创建的几个新聊天有设置，早期的好友聊天仍然是永久保存。

2. **计时器时间过长**：设置为30天或1周的消息消失计时器，在大多数场景下等于没设。真正需要保护的消息通常希望在几小时或1-2天内消失。

3. **对接收方不生效**：消失消息是双向的。如果对方没有启用或对方手动取消了设置，消息不会从对方设备上消失。

**加固方案**：

- 对敏感聊天设置较短的计时器（1小时到1天）
- 检查所有重要联系人的聊天是否都设置了消失消息
- 新建聊天时养成第一时间设置消失消息的习惯
- 在 Signal 设置中可以设置"新聊天默认计时器"（Signal → 设置 → 隐私 → 默认消失消息计时器）

[Signal 阅后即焚设置教程](/guides/disappearing-messages/) 有更详细的配置说明。

## 第6步：检查安全号码验证

Signal 的安全号码（safety number）是端到端加密的验证机制，可以防止中间人攻击。但几乎没有普通用户主动验证过。

**检查方法**：

打开任意一个聊天 → 点击联系人名字 → **查看安全号码**

安全号码是一串由数字和表情组成的指纹。你和对方设备上显示的号码应该完全一致。如果不一致，说明你们的通信可能被中间人劫持。

**风险评估**：

在正常情况下，安全号码不匹配极其罕见。但它能防御一种特定的高级攻击——有人在你和对方之间插入了一个"影子"设备，所有通信先经过攻击者再转发到对方。这种情况通常发生在国家级攻击者或有物理接触你设备的人身上。

对于大多数用户来说，安全号码验证是"可能永远不需要但关键时刻能救命"的操作。建议至少对你最重要的3-5个联系人验证一次安全号码。

**加固方案**：

- 对重要的联系人（合作伙伴、家人、密友）验证安全号码
- 如果安全号码发生变化（你或对方更换了设备），Signal 会提示你重新验证
- 不要忽略安全号码变更通知——这可能是中间人攻击的信号

[Signal 安全号码验证教程](/guides/safety-number/) 有详细的验证步骤说明。

## 第7步：检查注册锁和 PIN 码

注册锁和 PIN 码是防止账号被劫持的第二道防线。

**检查方法**：

打开 Signal → 左上角头像 → 设置 → 账号 → **注册锁**

**风险评估**：

如果没有启用注册锁，任何人在你的手机号收到 Signal 验证码后，都可以用这个验证码注册新设备并关联你的账号。这在以下场景中尤其危险：
- 你的手机号码被恶意转移（SIM卡劫持）
- 你收到了验证码短信但以为是垃圾短信而忽略了
- 有人在另一个国家用你的手机号注册 Signal

**加固方案**：

启用注册锁并设置强PIN码。PIN码应该是你不常用但能记住的4-8位数字。避免使用出生年月、手机尾号、银行卡密码等容易被猜测的组合。好的PIN码应该是你能记住但别人不容易关联到你的信息——比如你小时候的家庭电话号码的后4位、你第一次用的密码的前4位、或者一个对你有特殊意义但别人不知道的数字。如果忘记PIN码，必须等待7天的冷却期才能重设，所以务必记住。不要使用出生年月、手机尾号、银行卡密码等容易被猜测的组合。

[Signal PIN码与注册锁设置教程](/guides/signal-pin-registration-lock/) 有完整的配置说明。

## 第8步：检查本地存储安全

Signal 的消息存储在你的手机本地，如果手机本身不安全，所有加密保护都白费。

**检查项目**：

1. **手机锁屏是否启用**：没有锁屏密码的手机等于开放状态。任何拿到你手机的人都可以解锁后直接打开 Signal 阅读全部聊天记录。

2. **Signal 应用锁是否启用**：Signal 支持在每次打开应用时要求验证（PIN码、指纹或面容）。在设置 → 隐私 → 应用锁中开启。

3. **操作系统版本是否更新**：过期的操作系统可能存在已知安全漏洞。Signal 的加密保护的是传输过程，如果手机系统本身被攻破，本地的加密数据也可能被提取。

4. **是否安装了可疑应用**：安卓应用商店中有大量伪装成实用工具的间谍应用，如“系统工具”“手机加速器”“电池优化”等，这些应用往往请求截屏、录屏或无障碍服务等权限。定期检查已安装应用的权限，撤销不必要的截屏和录屏权限。安装来源不明的应用应立即卸载。：手机上的其他应用如果具有截屏、录屏或辅助功能权限，可以绕过 Signal 的安全保护直接记录屏幕内容。

**加固方案**：

- 启用手机锁屏密码（最好是6位以上或生物识别）
- 在 Signal 中启用应用锁
- 保持操作系统和应用更新到最新版本
- 定期检查手机上的应用权限，撤销不必要的截屏和录屏权限

## 第9步（附加）：检查备份安全

Signal 支持将聊天记录备份到本地或云端（Google Drive / iCloud）。备份虽然方便恢复数据，但也引入了额外的隐私风险。

**检查方法**：

打开 Signal → 左上角头像 → 设置 → 聊天 → **聊天备份**

**风险评估**：

如果你的备份没有启用 Signal 内置的加密，备份文件就是明文存储在你的 Google Drive 或 iCloud 上。这意味着：
- Google 或 Apple 可以在技术上访问你的备份内容
- 如果你的 Google/iCloud 账号被入侵，攻击者可以直接下载你的 Signal 聊天记录
- 云端备份可能在数据中心的冗余存储中保留比你预期更长的时间

Signal 从2024年开始提供了加密云端备份功能，但需要手动启用。如果你不确定自己是否启用了备份加密，现在就去检查。

**加固方案**：

- 如果启用了云端备份，确保备份加密已开启（设置中应有提示）
- 如果你不需要备份（设备之间迁移使用设备直连传输即可），可以关闭云端备份
- 定期清理旧的备份文件——Signal 可能保留了多个时间点的备份
- 如果你曾经在没有加密的情况下备份过，删除那些旧备份文件再创建加密备份

[Signal 备份聊天记录完整教程](/guides/backup/) 有详细的备份配置说明。

## 第10步（附加）：检查群组隐私

Signal 群组是隐私泄露的高风险场景。群组中的每个成员都能看到你发送的消息，群组设置也决定了你的身份暴露程度。

**检查项目**：

1. **群组类型**：你加入的群组是旧版群组还是新一代群组？旧版群组的成员列表对所有人可见，新一代群组的成员列表只有管理员可以看到。新一代群组在隐私保护上更优。

2. **群组邀请链接**：如果你创建了群组并分享了邀请链接，任何拥有链接的人都可以加入。检查你的群组是否设置了管理员审批加入。

3. **群组名称和头像**：你的群组名称和头像是否包含了你的真实姓名、工作单位或其他可识别信息？群组的名称和头像对所有成员可见，即使群组被转发或截图。

**加固方案**：

- 将重要的群组升级为新一代群组（如果尚未升级）
- 对公开群组设置管理员审批加入
- 避免在群组名称中使用可识别的个人或组织信息
- 定期审查你加入的群组列表，退出不再活跃的群组

[Signal 群组功能完整教程](/guides/group-chat/) 有详细的群组管理说明。

## 常见误区纠正

**"用了 Signal 就完全安全了"** — 这是最大的误区。Signal 提供的是传输安全，不是使用安全。加密能保证消息不被窃听，但不能保证你的手机不被偷、你的旧设备被忘记断开、你的使用习惯不被分析。

**"Signal 有消失消息所以聊天记录不会被泄露"** — 消失消息只是从设备上删除。在消息消失之前，接收方可以随时截图、复制或用其他设备拍摄。Disappearing messages 是减少数据留存时间，不是防止信息传播的魔法。

**"不用手机号注册就匿名了"** — Signal 用户名确实让你不需要暴露手机号就能添加好友，但 Signal 仍然知道你的手机号（注册时绑定的），如果你在同一个网络环境中同时使用 Signal 和其他服务，流量分析仍然可能关联你的身份。
