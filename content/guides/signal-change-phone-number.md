你换了个新手机号，第一个担心是什么？不是通讯录——现在没人存号码了。也不是微信——微信换号流程虽然烦但至少能迁移记录。

**最让人焦虑的是 Signal。**

里面可能有不想让任何人看到的聊天记录、工作群的敏感讨论、个人安全相关的设置。换手机号后这些还在吗？联系人还能找到你吗？旧号码会不会被运营商回收后别人注册你的 Signal？

好消息是：Signal 从 2022 年起就内置了"更改电话号码"功能，整个流程设计得相当完善。但坏消息是——**很多人操作时因为漏了几个前置步骤，导致聊天记录丢失或 PIN 码被锁。**

这篇文章不讲 Signal 怎么装、怎么注册。只讲一件事：**换号——怎么做、什么会丢、什么不会丢、有哪几个坑。**

## 一、Signal 换号前必须确认的三件事

打开 Signal 之前，先确认这三项。任何一项不满足，换号流程走不下去。

### 1. 旧手机号必须还能收短信/接电话

Signal 换号的第一步是**用旧号码验证身份**——系统会给旧号码发一条 6 位验证码（或打语音电话播报）。如果你的旧 SIM 卡已经扔了、号码已经注销了——到此为止，换号功能用不了。

**如果旧号码还没注销但 SIM 卡丢了：** 去运营商营业厅补办一张 SIM 卡。只要能收到短信就行。

**如果旧号码已经注销了：** 唯一的选择是用新号码重新注册 Signal，但聊天记录保不住。后面的内容不需要看了——这条路径救不回记录。

### 2. 确认你记得 PIN 码

Signal 换号过程中会要求输入 PIN 码做身份验证。如果不记得 PIN 码：

- Signal 设置 → 账户 → **更改我的 PIN 码** → 如果你现在能进入设置说明你知道当前 PIN
- 如果完全忘了：设置 → 账户 → 更改 PIN → 点击"忘记 PIN？"，按照提示操作（可能需要等待 7 天不活动期）

**在换号之前把 PIN 码搞定**——不要在换号流程中尝试回忆，一旦输错可能导致账号被临时锁定。

### 3. 确保是同一台手机

Signal 的换号功能设计为**同一设备上操作**。换新手机 + 换新号码 = 两个变量同时变，需要先在新手机上恢复聊天记录（用 Signal 的换机迁移功能），再换号。分两步走。

本文只覆盖"同设备换号"场景。"换手机 + 换号"的双重迁移将单独成文。

## 二、Signal 更换手机号完整操作步骤

确认三项前提都满足后，实际操作大约 3 分钟。

### 第 1 步：打开换号功能入口

Signal → 左上角头像 → **账户（Account）** → **更改电话号码（Change Phone Number）**

注意：不是"删除账户"——这两个选项挨得很近，点错了你的账号就没了。

点击后 Signal 会弹出一个确认界面，解释换号后会做什么：
- 你的聊天记录、群组、设置都会被保留
- 你的联系人会（可选）被通知你换了号码
- 旧号码将从 Signal 服务器上解绑

点击 **"继续（Continue）"**。

### 第 2 步：验证旧手机号

输入你当前的（旧）手机号，注意选择正确的国家代码（中国大陆 +86）。

点击"下一步"后，Signal 会给旧号码发送一条 6 位数验证码短信。

收到后输入验证码。如果 60 秒内没收到：
- 检查是否输入了正确的号码和国家代码
- 点击"重发验证码"
- 如果短信一直收不到，点击"通过电话接收验证码"——Signal 会打语音电话播报验证码（英文播报，数字部分听清就行）

### 第 3 步：输入 PIN 码

验证旧号码通过后，系统会弹出 PIN 码输入界面。

输入你设置的 Signal PIN（至少 4 位数）。

这里是最容易卡住的地方。如果忘记 PIN 码，点击"忘记 PIN"会触发 Signal 的 PIN 恢复流程——需要等待一段不活动期（最长 7 天）才能重置。**没有绕过 PIN 的方式。**

### 第 4 步：输入新手机号

PIN 验证通过后，输入你的新手机号。同样注意选择正确的国家代码。

点击"下一步"，Signal 会给新号码发送验证码。输入验证码完成新号码绑定。

### 第 5 步：选择是否通知联系人

换号完成瞬间，Signal 会弹出最后一个选项：

**"通知我的 Signal 联系人我更换了手机号？"**

- **建议选"通知"**：Signal 会向所有已有聊天会话发送一条系统消息（不是你手动发），告知对方你更换了手机号。对方通讯录里的 Signal 联系人会自动更新为新号码，不影响任何聊天记录。
- **选"不通知"**：联系人不会知道。但对方给你发消息时仍能正常发送到新号码（因为旧号码已解绑）。不过对方可能会困惑"这个人怎么没回复"。

选了"通知"后，不需要你做任何额外操作——Signal 自动处理。

### 换号完成后立即检查的三件事

换号成功后，花 30 秒验证以下三项：

1. **聊天记录完整性**：打开最近几个聊天会话，确认消息、图片、文件都还在
2. **群组成员身份**：随便打开一个群组，确认自己仍在群里，身份没变
3. **注册锁状态**：设置 → 账户 → **注册锁（Registration Lock）** → 确认开启

## 三、换号会影响什么？不会影响什么？

| 不受影响（自动迁移） | 说明 |
|------|------|
| 所有聊天记录 | 文字、图片、文件、语音消息全部保留 |
| 群组成员身份 | 自动迁移，不会退出任何群组 |
| 联系人列表 | 保留，对方看到的还是你 |
| PIN 码 | 不变 |
| 注册锁 | 不变 |
| 隐私设置 | 已读回执、在线状态、电话号码可见性等全部保留 |
| 屏蔽列表 | 保留 |
| 关联设备 | 桌面版、iPad 版保持登录，不需要重新关联 |
| 用户名 | 不变 |

| 需要注意 | 说明 |
|------|------|
| 联系人看到的号码 | 如果通知联系人，他们会看到新号码。建议在隐私设置中限制谁可以看到你的号码 |
| 旧号码安全性 | 旧号码解绑后 7 天内如果没人知道你的 PIN，旧号码无法被重新注册 |
| 通知联系人 | 会发送系统消息，不是手动发消息，不尴尬 |

## 四、换号后的安全收尾（3 步防旧号被冒用）

换号完成不代表安全收工。你现在面临一个新风险：**旧 SIM 卡和旧号码还在不在你手上？**

### 1. 销毁旧 SIM 卡

如果你换了新 SIM 卡，旧的还在手上——**物理剪断**。

旧 SIM 卡虽然无法接收 Signal 验证码（因为号码已经转移到新 SIM），但它仍可能被用于其他验证渠道。直接物理销毁是最保险的做法。

### 2. 确认注册锁已开启

设置 → 账户 → **注册锁** → 确保显示 "已开启"。

注册锁的作用：如果有人拿到你的旧号码，试图注册 Signal，系统会要求输入你的 PIN 码。不知道 PIN 码 → 需要等待 7 天不活动期 → 7 天后才能注册。但前提是注册锁必须开启。

### 3. 检查关联设备

设置 → 关联设备 → 确认列表中只有你自己授权的设备。

换号不会自动踢掉关联设备，建议在这个页面上看一眼有没有不认识的设备，有的话踢掉。

## 五、特殊情况处理

### 你在海外，新老号码都是海外号

Signal 的换号功能**完全支持跨国号码更换**。比如从中国 +86 换到美国 +1——操作流程完全一样，只需要在输入号码时选择正确的国家代码。

跨国换号后，发送"通知联系人"的系统消息时，对方通讯录里的联系人信息会自动更新。

### 你用的是虚拟号码注册的 Signal

Signal 可能拦截虚拟号码平台的验证码。如果你通过第三方虚拟号码平台注册的 Signal，换号流程可能失败。

建议：不要用虚拟号码注册 Signal。已经注册了的，换号时换成真实号码。

### 换号后桌面版提示需要重新关联

少数情况下换号后桌面版会断开连接。解决方式：手机端 Signal → 设置 → 关联设备 → 重新扫描桌面版的二维码即可。聊天记录不受影响。

---

Signal 的换号功能是同类加密聊天软件中做得最完善的。WhatsApp 也可以换号留记录但需要手动备份到云端（这意味着加密保护降低），Telegram 换号更容易但记录全在云端。Signal 在换号时完全避免云端中转——所有数据在本地完成迁移，一条消息都没经过服务器。

如果你现在手上有两张 SIM 卡，旧卡还能收短信，花 3 分钟换号，比等到旧号码注销之后再手忙脚乱好一万倍。
