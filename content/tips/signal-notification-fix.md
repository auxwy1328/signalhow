Signal 是一款端到端加密的即时通讯软件，安全性没得说。但如果你收不到消息通知，安全性再高也没意义——你根本不知道有人找你。

这个问题在国内 Signal 用户中极其常见，尤其是安卓用户。说实话，大多数人第一反应是"Signal 又崩了"，但实际上，问题根源往往不在 Signal，而在**你的手机系统**。

这篇文章我会从最常见到最罕见，逐一排查 7 种原因。每种原因都会告诉你：

- 为什么会出现这个问题
- 具体怎么修（按手机品牌分开讲）
- 修完之后怎么验证是否生效

**各品牌手机操作路径不同，我会把国产主流品牌（小米/华为/OPPO/vivo/三星）和 iOS 的方法都列出来。**

---

## 方法一：关闭电池优化（最常见原因，占 80%）

这是头号嫌疑犯。

安卓手机为了省电，会主动杀死后台 App。Signal 需要维持一条长连接到服务器才能即时收到推送，系统把它杀了，消息自然收不到。

**怎么确认：** 打开 Signal → 收到一堆积压消息弹出来 → 说明你中招了。

**修复方法（按品牌）：**

| 品牌 | 操作路径 |
|------|---------|
| 小米/HyperOS | 设置 → 应用设置 → Signal → 省电策略 → **无限制** |
| 华为/HarmonyOS | 设置 → 应用 → 应用启动管理 → 找到 Signal → 关闭"自动管理" → 手动开启**自启动、关联启动、后台活动**三个开关 |
| OPPO/ColorOS | 设置 → 应用 → Signal → 耗电保护 → **允许后台运行** |
| vivo/OriginOS | 设置 → 应用与权限 → Signal → 权限 → 单项权限设置 → 开启**自启动**；再回到应用页 → 耗电管理 → **允许后台高耗电** |
| 三星/OneUI | 设置 → 应用程序 → Signal → 电池 → **不受限制** |
| 原生安卓/Pixel | 设置 → 应用 → Signal → 应用电池用量 → **不受限制** |
| iOS | 设置 → 通用 → 后台 App 刷新 → 确保 **Signal 开关是打开的** |

**修完怎么验证：** 让朋友给你发一条消息，锁屏等待 1 分钟。如果锁屏状态下弹出通知，说明修好了。

---

## 方法二：锁定 Signal 在最近任务列表

光关电池优化还不够。很多国产手机在内存不足时会清理最近任务列表里的 App——跟杀进程差不多效果。

**操作：** 打开 Signal → 进入最近任务/多任务界面 → 长按 Signal 卡片 → 点**锁定**（小米/华为/OPPO/vivo 都有这个功能，通常是一个小锁图标）。

锁定后，Signal 卡片上会出现一个锁的标记，系统就不会自动清理它了。

这是一个小动作，但能解决很多"不知道怎么就收不到了"的问题。

## 方法三：华为/无 GMS 手机的额外设置

这是华为用户专属的痛。因为华为手机没有 Google Play Services（GMS），Signal 无法使用 Google 的 FCM 推送通道，只能用 WebSocket 长连接替代——而 WebSocket 连接在华为的系统里更容易被杀。

除了方法一和方法二，华为用户还需要做以下几步：

**1. 忽略电池优化（深层设置）：**
设置 → 应用 → Signal → 电池 → **手动管理** → 全部开启

**2. 开启通知权限（双重点检查）：**
华为系统有两层通知控制：系统层面的和 App 层面的。两个都要开。
- 设置 → 通知 → Signal → 允许通知（全部类型勾选）
- Signal 内 → 设置 → 通知 → 确认所有通知类型已开启

**3. 关闭"省电模式"：**
省电模式下，华为会自动限制所有第三方 App 的后台活动。如果白天不能关省电模式，至少确保在需要接收 Signal 消息的时段关闭它。

---

## 方法四：检查系统通知权限

这个问题听起来低级，但经常被忽略——你在装 Signal 的时候不小心点了"不允许通知"，之后就忘了。

**检查清单：**

- [ ] 系统设置里 Signal 的通知权限是否开启
- [ ] 锁屏通知是否开启（显示所有通知内容）
- [ ] 横幅/弹窗通知是否开启
- [ ] 声音和振动是否开启
- [ ] 勿扰模式下是否允许 Signal 的通知

**iOS 额外检查：** 设置 → 通知 → Signal → 确保"允许通知"开启 + 勾选所有三种提醒（锁定屏幕、通知中心、横幅）+ 打开"声音"

**安卓额外检查：** 长按 Signal 图标 → 应用信息 → 通知 → 逐项检查每个通知类别（消息、通话、群组等）是否开启

---

## 方法五：检查专注模式/勿扰模式

很多人开了专注模式/睡眠模式就忘了关，然后疑惑"Signal 怎么不响了"。

**iOS：** 设置 → 专注模式 → 如果"睡眠""工作""个人"等模式中任何一个开启了，Signal 的消息可能被静音。你可以：要么关闭专注模式，要么在专注模式的"允许的 App"里把 Signal 加进去。

**安卓：** 设置 → 通知 → 勿扰模式 → 检查是否开启。如果开启了，点"例外"→ 把 Signal 加入允许列表。

**为什么这个排查常被漏掉：** 大多数人只会检查"通知"这个大开关，但不知道通知下面还有子分类。如果你把"消息通知"开了但"群组通知"关了，那么一对一的消息能收到，群聊消息收不到——你会误以为 Signal 时灵时不灵，其实只是部分通知类型被关了。

![专注模式下允许 Signal 通知](/images/tips/signal-notification-fix/body2.jpg)

## 方法六：Signal 内部通知设置

如果上述系统层面的设置都正确，问题可能在 Signal 自己的设置里。

**打开 Signal → 设置 → 通知，逐项检查：**

1. **消息通知** — 必须开启。下面可以分别设置"声音""振动""指示灯"。
2. **静音未知来电** — 这个功能默认开启，会把不在通讯录里的人的通话静音。不影响消息，但如果你在等陌生人的通话，关掉它。
3. **应用内通知** — 当你正在 Signal 里聊天时，其他对话的新消息是否提示。
4. **通知内容** — 建议设置为"显示名称和内容"，这样锁屏也能看到谁发了什么。

**一个容易被忽略的设置：** Signal → 设置 → 隐私 → 通讯录权限。如果你没给 Signal 通讯录权限，消息通知可能只显示电话号码而不是联系人名字——虽然不影响收到通知，但很多人会以为"没收到消息"（因为显示的是陌生号码）。

## 补充排查：Signal 消息通知延迟但最终能收到

如果你的 Signal 不是完全收不到通知，而是延迟 5-10 分钟才收到，通常是以下原因：

**1. 省电模式是间歇性的。** 很多手机在屏幕关闭 5 分钟后自动进入省电模式，此时后台连接被切断。等屏幕再次亮起时连接恢复，积压的消息一起弹出来。

**2. 数据节省模式（Data Saver）。** 安卓的"数据节省"功能会阻止后台 App 使用移动数据。如果 Signal 走的是移动数据而非 Wi-Fi，消息会延迟到屏幕亮起才送达。关掉它的路径：设置 → 连接 → 数据使用 → 数据节省 → 关闭，或者把 Signal 加入"不受限制的应用"白名单。

**3. Wi-Fi 睡眠策略。** 安卓默认在屏幕关闭一段时间后将 Wi-Fi 设为休眠——这个过程会中断 Signal 的连接。修改方法：设置 → WLAN → 高级设置 → 在休眠状态下保持 WLAN 连接 → **始终**。

![通知权限子分类检查](/images/tips/signal-notification-fix/body3.jpg)

## 方法七：网络问题排查

Signal 的推送通知依赖稳定的网络连接。如果你用了代理、VPN 或防火墙，可能影响通知推送。

**排查步骤：**

1. **关闭 VPN/代理** → 等 2 分钟 → 让朋友发一条消息 → 看能不能收到。如果能收到，说明你的 VPN/代理规则需要调整，把 Signal 的域名加入直连白名单。
2. **切换 Wi-Fi 到移动数据**（反之亦然）→ 如果切换后立刻收到消息，说明之前的网络对 Signal 连接有限制。
3. **检查是否开了私人 DNS**（安卓）→ 设置 → 连接 → 更多连接设置 → 私人 DNS → 如果设成了某个 DNS 提供商（如 AdGuard DNS），部分 DNS 可能会误拦 Signal 的推送服务器。先临时切回"自动"，看通知是否恢复。

**一个冷门但真实存在的原因：** 某些公共 Wi-Fi（机场、酒店）封了非标准端口的 WebSocket 连接，Signal 在这些网络下无法维持推送通道。这种场景下，切到移动数据是唯一解。

## 如果以上都试了还不行

到了这一步，不太常见但仍有几种可能性：

**1. Signal 服务器端问题。** 虽然很少发生，但 Signal 有时会短暂宕机。检查方法：打开 [status.signal.org](https://status.signal.org) 查看服务状态。

**2. App 版本过旧。** 打开 Signal → 设置 → 拉到最下面 → 检查版本号。如果比应用商店里的低，更新它。

**3. 重新安装 Signal。** 最后手段。注意：**卸载前务必备份**（设置 → 聊天 → 聊天备份 → 创建备份）。重新安装后恢复备份即可。

**4. Google Play Services 被冻结/禁用。** 国产手机经常有这个操作。打开手机设置搜索"Google Play Services" → 如果显示"已停用"，启用它。Signal 的 FCM 推送依赖这个服务。

## 快速排查流程图

如果你懒得读上面所有内容，按这个顺序来：

```
第一步（80%能解决）→ 关闭电池优化 + 锁定最近任务
          ↓ 还不行
第二步 → 检查系统通知权限是否全部开启
          ↓ 还不行  
第三步 → 关闭勿扰/专注/省电模式
          ↓ 还不行
第四步 → 检查 Signal 内部通知设置
          ↓ 还不行
第五步 → 排查 VPN/代理/私人 DNS/公共 Wi-Fi
          ↓ 还不行
第六步 → 更新 App + 检查 status.signal.org
```

通常到第一步就解决了。如果你到了第四步还没解决，问题大概率不是 Signal 的事——回头检查手机系统设置。
