## 先说结论：卸载 App ≠ 注销账号，两步都要做才算"离开"

![Signal 账号注销与数据清除完整指南封面](/images/tips/signal-delete-account-data/cover.jpg)

很多人以为把 Signal 从手机删了就完事了。不是。

Signal 的账号系统是这样工作的：你的手机号在 Signal 服务器上注册了一个"存在记录"——不包含聊天记录（Signal 没有聊天记录服务器），但包含"这个手机号是一个活跃 Signal 用户"这个事实。

卸载 App → 你的聊天记录从手机本地删除 ✅ → 但你的手机号依然在 Signal 的注册名单里 ❌

**真正离开 Signal 需要两步：**
1. 在 App 里**注销账号**（删除服务器上的注册记录）
2. **卸载 App**（删除手机上的本地数据）

顺序不能反——先卸载 App 就没法注销了，只能用 Signal 网页端的注销工具（后面会讲）。

## 注销前必须做的 4 件事

很多人急着注销，点了就跑。但有几件事做了比不做好。

### 1. 关闭注册锁（Registration Lock）

**这个是最大的坑。**

Signal PIN 和注册锁是什么关系？简单说：PIN 是加密密钥的保护密码，注册锁是"重新注册这个手机号需要 PIN"的开关。如果你开着注册锁就注销了，7 天内想重新注册会被要求输入 PIN。忘了 PIN？那就等 7 天。

关闭路径：**设置 → 账号 → 注册锁 → 关闭**

说实话，Signal 的注册锁设计很矛盾——它用 PIN 保护你的账号不被别人劫持，但 PIN 本身又没有恢复机制。忘了就是忘了。注销前最好是先关掉，不留后患。

### 2. 导出你想保留的聊天记录

Signal 支持加密导出聊天记录（Android）或逐对话保存（iOS）。路径：**设置 → 聊天 → 聊天备份 → 创建备份**

Android 端的备份是一个加密文件，需要输入 30 位密码短语才能恢复。这个备份**只能在 Android 端恢复**，不能跨平台导入 iOS。如果你是 iOS 用户，只能用逐个对话的"导出聊天"功能存为纯文本文件。

### 3. 通知重要联系人

这个不是技术步骤，但很实用。你注销 Signal 后，还在用 Signal 的联系人会看到你的聊天变成"无法发送消息"状态。提前告知一声可以避免别人担心"是不是被拉黑了"。

### 4. 清除关联设备的聊天数据

Signal 桌面版（Windows/Mac/Linux）存储了独立的消息数据库。注销前在每个设备上单独操作：**设置 → 清除数据**。只注销手机不会自动清除桌面版的数据。

## 正式注销：三步操作

![Signal 账号注销操作步骤截图](/images/tips/signal-delete-account-data/steps.jpg)

### 手机端（推荐）

1. 打开 Signal → 点左上角头像 → **设置**
2. 滑到底部 → **账号** 
3. 点 **删除账号** → 输入你的手机号确认 → 点 **删除**

你的账号立即注销。所有本地聊天记录同步删除。

### 桌面端注销

桌面版不能直接注销账号——它只是手机的"镜像"。正确做法是在手机上注销，然后打开桌面版 → **设置 → 清除数据**（桌面版会自动检测到手机已注销）。

### 特殊情况：手机丢了/坏了/App 已卸载

如果你已经卸载了 Signal 但没注销账号，可以用 Signal 官方提供的网页注销工具：

访问 `signal.org` → 搜索 "account deletion" → 按指引输入手机号接收验证码 → 确认注销。

注意：这个网页工具在部分国家可能需要梯子才能访问。

## 注销后：数据去哪了、别人看到什么

这是隐私用户最关心的问题。

### 你的数据

| 数据类型 | 注销后的状态 |
|---------|------------|
| 手机本地聊天记录 | 已删除（随账号注销同步清除） |
| Signal 服务器上的聊天记录 | 从未存在过（Signal 不存储消息） |
| 你的 Signal 个人资料（头像、名字） | 从服务器删除 |
| 你的 Profile Key（加密个人资料密钥） | 立即作废 |
| 你的 Signal PIN | 保留 7 天随后自动作废 |
| 桌面版的数据 | 依然存在！手动清除 |

### 别人看到什么

注销后，你的联系人那边的变化是渐进的：

**立即效果（几秒内）：**
- 在群组里你的名字变成"未知用户"
- 私聊窗口顶部不再显示"在线"状态

**短期效果（24-48 小时）：**
- 联系人通讯录刷新后，你的手机号旁显示"邀请加入 Signal"而非你的头像
- 别人无法给你发新的 Signal 消息

**不会变的：**
- 对方的聊天记录仍然完整 → 和你的旧对话依然可以翻阅
- 群组聊天记录中你发过的消息不会消失 → Signal 的消息是各自存储的

![Signal 注销前后对比：别人看到的变化](/images/tips/signal-delete-account-data/before-after.jpg)

**一个容易被忽略的细节：**你在群组里发的消息上有你的个人资料（名字、头像）。注销后这些信息变成"未知用户"，但消息内容本身不会消失。如果你在注销前想彻底清理痕迹，需要退出所有群组→再逐个删除你在群组里发过的消息→然后注销。坦白讲，这操作很繁琐，多数人不会做。

## 重新注册同一个手机号

注销后如果想回来，规则是这样：

| 时间窗口 | 条件 | 结果 |
|---------|------|------|
| 7 天内 | 未关闭注册锁 | 需要输入原 PIN 才能注册 |
| 7 天内 | 已关闭注册锁 | 直接注册，无需 PIN |
| 超过 7 天 | 不管什么状态 | 直接注册，注册锁自动失效 |

所以如果你只是"暂时离开一段时间"，建议先关闭注册锁再注销，这样回来时不麻烦。

## 终极隐私：注销前把所有痕迹清干净

如果你需要最彻底的清理（比如彻底离开 Signal 且不想被任何历史记录关联），按这个顺序操作：

1. **逐群退出**：退出所有群组（退出后你在群里的消息保留但名字变"未知"）
2. **逐对话删除**：打开每个私聊 → 删除对话（这会在对方那里显示"X 已删除对话"的通知，无法避免）
3. **取消关联桌面版**：每个桌面设备 → 清除数据
4. **关闭注册锁**：设置 → 账号 → 注册锁 → 关闭
5. **注销手机号**：设置 → 账号 → 删除账号
6. **等 7 天**：确保你的手机号从 Signal 系统中完全移除

![Signal PIN和注册锁关闭操作说明](/images/tips/signal-delete-account-data/pin-removal.jpg)

说实话，第 1、2 步很少有人会做——太费时间了。对大多数用户来说，直接注销就够了。只有你需要"这个人从来没用过 Signal"级别的痕迹清理时才需要这么彻底。

## FAQ

### 卸载 Signal App 就算注销账号了吗？

不算。卸载 App 只删除本地数据，服务器上的注册记录还在。必须通过设置里的删除账号功能正式注销。

### Signal 注销账号后聊天记录会怎样？

你的手机本地聊天记录被删除，对方手机上的聊天记录不受影响。Signal 服务器不存储聊天记录。

### Signal 注销后别人还能搜到我的手机号吗？

24-48 小时后不能。对方的通讯录刷新后你的号码旁会显示"邀请加入 Signal"而非你的头像。

### Signal 注册锁在注销前需要关闭吗？

建议关闭。否则 7 天内重新注册会被 PIN 卡住。路径：设置 → 账号 → 注册锁 → 关闭。

### Signal 注销账号需要多长时间？

点击确认后即时生效。但手机号从系统完全移除需要 24-48 小时缓存刷新。

### Signal 账号注销后还能恢复吗？

不能。账号及本地数据永久删除，没有恢复途径。7 天内重新注册需要 PIN（如果注册锁未关）。
